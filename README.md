# La Reta · Pádel Tepic

App de retas, marcadores y ranking de pádel.

- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`, `fonts/`: la app instalable que se publica en GitHub Pages.
- `apps-script/`: el servidor en Google Apps Script (va pegado en la hoja **LA RETA · Pádel Tepic**). Los datos viven en esa hoja.
